# Teggy

Версии используют формат `MAJOR.MINOR.PATCH`:

- `MAJOR` — несовместимые изменения;
- `MINOR` — новые возможности без нарушения совместимости;
- `PATCH` — исправления ошибок.

## 2.0.0

### Новое

- Новый интерфейс на PySide6
- 5 тем оформления
- Drag & Drop
- Шаблоны метаданных
- Генератор SEO-тегов
- Конвертация PNG/WebP/BMP/TIFF → JPG
- Полная очистка EXIF перед записью
- Запись рейтинга Windows
- Многопоточная обработка
- Логирование
- Настройки пользователя
